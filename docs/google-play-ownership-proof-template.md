# RotorReady Google Play ownership proof template

Use this as a source template for a PDF attachment to a Google Play appeal. Put the final text on Mayday AS letterhead, export it as PDF, and sign it.

Do not include passwords, private keys, service account JSON, cookies, tokens, or registrar login details.

## Document checklist

Create one PDF containing:

1. Signed declaration from Mayday AS.
2. Domain ownership/admin proof for `rotor-ready.com`.
3. Optional hosting/admin proof showing Mayday AS controls the RotorReady deployment.
4. Statement that RotorReady is not an affiliate/referral/traffic-arbitrage app.

## Page 2: domain ownership/admin proof

Attach or describe one or more formal proofs. Redact private data that is not needed.

Recommended options:

- Domain registrar record showing Mayday AS or the authorized administrator controls `rotor-ready.com`.
- DNS zone/admin export showing control of `rotor-ready.com`.
- Google Search Console ownership verification for `rotor-ready.com`.
- DNS TXT verification record created specifically to prove domain control.
- Vercel domain/project screen or export showing `rotor-ready.com` is configured in the RotorReady project controlled by Mayday AS.

Suggested text:

The following attached evidence shows that Mayday AS owns and/or administers `rotor-ready.com` and controls the RotorReady deployment served from that domain.

## Page 3: app and website relationship

RotorReady for Android is the first-party mobile app for the RotorReady service. The Android app uses Capacitor to display RotorReady content from the official RotorReady domain, `https://rotor-ready.com`, which is owned/administered by Mayday AS.

The app provides RotorReady training functionality including aircraft-specific quiz banks, emergency/malfunction training, procedures, limitations, systems knowledge, and offline packages. It is not a wrapper for a third-party website and does not provide affiliate/referral traffic.
