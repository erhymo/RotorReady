# Question Authoring Protocol

## Code phrase

When the user says:

> La oss lage flere spørsmål

use this protocol before creating or editing any quiz questions.

## Core rule

Never invent aviation facts, limits, numbers, procedures, conditions, terminology, or correct answers.

Questions may only be based on source material available in the repository, primarily:

- QRH content
- RFM content
- existing structured app data derived from QRH/RFM

If the source does not clearly support a question, do not write the question.

## Workflow

1. Identify the target aircraft, topic, and quiz section.
   - Example: AW169, Limitations, PC/OPC preparation.
2. Read the existing question bank for that aircraft/topic.
3. Read the relevant QRH/RFM source material in the repository.
4. Find gaps that are useful for pilot training.
5. Avoid duplicates and near-duplicates.
6. Prefer quality over quantity.
7. If there are not enough strong source-backed candidates, say so clearly.

## Quality standard

Questions should be suitable for pilots preparing for PC/OPC.

Good questions should be:

- operationally relevant
- source-backed
- unambiguous
- concise enough for mobile use
- focused on decision-making, recognition, limitations, conditions, or correct application
- written in professional aviation English

Avoid questions that are:

- trivia without operational value
- based on guessed numbers or inferred limits
- duplicated from existing questions
- ambiguous or dependent on wording tricks
- too easy if the source supports a better applied question

## Preferred question style

Use a mix of:

- direct limitation recall
- scenario-based application
- "which statement is correct?"
- recognition of exceeded/approached limits
- condition-based questions, e.g. when a limit applies

Use "which statement is NOT correct?" sparingly.

Distractors should be plausible and source-aware, for example:

- nearby but incorrect values
- wrong phase of flight
- wrong condition
- continuous vs transient confusion
- AEO vs OEI confusion
- normal vs emergency limitation confusion

## Safety and review

All generated questions are draft training content until reviewed by a qualified subject-matter expert.

For each batch, summarize:

- source area used
- topics covered
- why the questions are not duplicates
- any items that need human review

If no more high-quality source-backed questions are available in the current area, say:

> I do not see enough remaining source-backed, non-duplicate, high-quality questions in this area right now.
