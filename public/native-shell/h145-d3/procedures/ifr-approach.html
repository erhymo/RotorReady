IFR APPROACH PROCEDURES

Normal procedure
CAUTION

When using altitude constrained legs, the baro setting must be identical on MFD1 and MFD2. The crew must remember to synchronize the baro setting whenever it was changed.

CAUTION

Before engaging the autopilot via the CPL button on the MFD, the course pointer (CRS) must be set to the published approach course. An incorrectly set course pointer may lead to significant track deviations.

ILS approach
1
— Before intercepting the final approach course: both GTN units — Set ILS frequency
2
— NAV sk on MFD2 — Select ILS2; minimum LOC interception distance 4 NM; automatic LOC/GS capture within 2 dots (LOC) / 0.5 dots (GS)
3
— At the decision altitude/height: if safe landing using visual references is assured, perform landing; if not, perform missed approach
LNAV/LP or LPV/LNAV-VNAV approach
1
— Before the IAF: approach procedure — Select and activate; navigation mode (FND/NAVD) — Check GPS or SBAS
2
— Baro settings — Check; DA and DH — Set to approach minima; autopilot NAV mode — CPL
3
— If autopilot IAS mode is engaged during LPV/LNAV-VNAV: it will automatically adjust IAS for a max rate of descent of 1000 ft/min
Missed approach (GPS approaches only)
1
— Before the MAP but after the FAF: FLIGHT PLAN page on GTN — MENU sk — ACTIVATE GPS MISSED APPROACH sk
2
— At or after the MAP: check SUSP appears; GA pb on collective — Push
3
— Continue with the appropriate approach procedure for the next attempt
Note

Using the GA pb on the collective to initiate a missed approach keeps the autopilot coupled on NAV mode with automatic waypoint sequencing provided.

Source: FLM BK117 D-3 Sect. 4.13.4
